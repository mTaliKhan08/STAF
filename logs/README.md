# STAF Training & Validation Logs

This directory contains the training logs and loss progressions for STAF models:
1. `training_50epochs.log`: Raw 50-epoch training console log on CARLA.
2. `original_50epochs/`: Parsed epoch-by-epoch loss, validation ADE, and soft-gating attention weights.
3. `phase1_progression/`: Phase 1 training and validation loss progression across epochs.
